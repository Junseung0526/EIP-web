# 정보처리기사 학습 노트

정보처리기사 1·2과목 중간고사 대비 학습 사이트입니다. 교수님이 지정한 범위 64개 항목을 개념 설명, SVG 도해, 시뮬레이터, 예상문제, 암기카드로 정리했습니다.

- 빌드 도구가 없는 정적 사이트(HTML · CSS · JavaScript)
- 모든 도해는 JS로 생성하는 인라인 SVG이며 다크/라이트 테마를 따릅니다
- 학습 진도, 오답 노트, 카드 암기 상태는 브라우저 `localStorage`에 저장됩니다

## 화면 구성

| 영역 | 내용 |
|---|---|
| 왼쪽 목차 | 과목 → 장 → 절 번호(예: 2.5)로 구성, 학습 완료 표시와 진도 카운트 |
| 본문 | 출제 포인트 → 개념 → 도해(`fig.N`) → 표 → 암기 요령 순서, 섹션 번호 자동 부여 |
| 오른쪽 레일 | "이 페이지" 목차(스크롤 위치 연동), 학습 완료·문제·암기카드 바로가기 |
| 상단 바 | 검색(`/` 키로 포커스), 범위 · 문제풀이 · 암기카드 · 핵심 요약, 다크/라이트 전환 |

디자인은 라이트 모드를 기본으로 하는 개발자 문서 스타일입니다(Pretendard + JetBrains Mono). 다크 테마는 상단 버튼으로 전환할 수 있고 선택값은 저장됩니다. 운영체제의 "동작 줄이기" 설정(`prefers-reduced-motion`)을 켜면 모든 애니메이션이 꺼집니다.

## 학습 콘텐츠

| 구분 | 내용 |
|---|---|
| 학습 페이지 68개 | 1과목: 개발 모형 · 요구사항 · UML · UI와 품질 · 아키텍처 패턴 · 객체지향 설계 · GoF 23패턴<br>2과목: 자료구조 · 정렬/해싱 · 패키징/DRM · 형상 관리 · 애플리케이션 테스트 · 시간복잡도 · EAI/JSON/IPSec |
| SVG 도해 50여 종 | 개발 모형, UML 13종, 디자인 패턴 23종 구조도, V-모델, 드라이버/스텁, IPSec 패킷 구조 등 |
| 문제풀이 | 예상문제 157문항, 과목·주제별 풀이, 오답 노트, 모의고사(20문항) |
| 암기카드 | 주제별 카드와 GoF 패턴 카드(자동 생성), 모르는 카드만 보기 |
| 핵심 요약 | 암기 요령 모음과 회전별 정렬 결과 표 |

> 문제 은행은 기출 **유형**을 바탕으로 만든 예상문제입니다. 교수님이 직접 언급한 2문항(영어 동치 분할 문제, 정렬 복잡도 문제)만 실제 출제 문항이며 `src: 'prof'`로 구분했습니다. 용어와 정답은 수업 자료와 대조해 확인하세요.

## 시뮬레이터와 실습 도구

슬라이더, 버튼, 직접 드래그로 조작하며 개념을 확인합니다. 값이 바뀔 때는 `requestAnimationFrame` 이징으로 부드럽게 따라갑니다.

| 주제 | 도구 |
|---|---|
| 트리 | 전위·중위·후위 순회 경로 애니메이션, 노드별 차수·레벨 확인 |
| 수식 | 중위 → 후위·전위 변환기(스택 변화 표와 수식 트리) |
| 자료구조 | 스택(삽입·삭제 애니메이션, TOP 포인터), 그래프 최대 간선 수, 해시 테이블(충돌 해결 3종) |
| 정렬 | 삽입·선택·버블·합병 정렬 단계 재생(막대가 실제로 이동), 회전별 결과 표 |
| 테스트 | 화이트박스 커버리지 판정기, 동치 분할·경계값 탐침(마커 드래그), 스텁/드라이버 통합 시뮬레이터 |
| 복잡도 | n 슬라이더로 O(1) ~ O(2ⁿ) 비교 |
| 통합·보안 | EAI 유형별 연결 수 비교, IPSec 프로토콜·모드 선택기, JSON 구조 분석기 |
| 형상 관리 | 저장소와 작업 디렉터리 시뮬레이터(동료 커밋, 충돌 해결 포함) |
| 설계 | 결합도·응집도 단계별 코드 예제, UML 관계 맞추기, 패턴 키워드 게임 |

```

js/svg.js               SVG 헬퍼, 클래스 다이어그램 렌더러, 이징 함수(S.ease)
js/diagrams1.js         1과목 정적 도해
js/diagrams2.js         2과목 정적 도해
js/patterns.js          GoF 23패턴 데이터와 카드 렌더러
js/interactive.js       시뮬레이터 (트리 순회, 정렬, 스택, 해시, 변환기 등)
js/labs.js              실습 도구 (커버리지, 탐침, 버전 관리, IPSec 등)
js/data/subject*.js     학습 페이지 본문
js/data/scope.js        교수님 지정 범위와 학습 페이지 매핑
js/data/quiz.js         문제 은행
js/app.js               라우터, 사이드바, 오른쪽 목차, 퀴즈, 암기카드, 검색
scripts/check.mjs       데이터 무결성 검사
.github/workflows/      검사와 GitHub Pages 배포
```

## 로컬 실행

```bash
python3 -m http.server 8000     # http://localhost:8000
node scripts/check.mjs          # 데이터 무결성 검사
```

`file://`로 `index.html`을 직접 열어도 동작합니다. 글꼴(Pretendard, JetBrains Mono)은 CDN에서 불러오며, 오프라인이면 시스템 글꼴로 대체됩니다.

## 콘텐츠 추가

- 학습 페이지: `js/data/subject*.js`에서 `addTopic({ id, subj, group, title, en, exam, body, cards })`
- 시험 범위 항목: `js/data/scope.js`에 `[과목, 라벨, 토픽 id]` 추가
- 문제: `js/data/quiz.js`의 `q(토픽 id, 문제, [보기], 정답 번호, 해설)`
- 도해: `js/diagrams*.js`에서 `DIAGRAMS.이름 = () => svg문자열`을 만들고 본문에서 `fig('이름', '캡션')` 호출
- 인터랙티브 도해: `DIAGRAMS.이름 = (el, arg) => { el.innerHTML = ...; }` 형태로 요소를 직접 채움

### 도해 작성 기준

- 흰 글자(`c: 'w'`)는 `hot` 계열 진한 배경 위에서만 사용합니다. `B()` 헬퍼는 `hot` 박스에 자동으로 적용합니다.
- 글자는 박스·도면 밖으로 나가거나 다른 글자와 겹치지 않아야 합니다.
- 색은 CSS 변수(`--a` ~ `--f`, `--accent`)만 사용해 두 테마에서 모두 읽히게 합니다.
- 값이 연속적으로 바뀌는 도해는 DOM을 재생성하지 말고 `S.ease`로 보간하거나 클래스·transform만 갱신합니다.

## 배포 (GitHub Pages)

`.github/workflows/deploy.yml`이 다음을 수행합니다.

1. 모든 PR과 `main` 푸시: JS 문법 검사와 `node scripts/check.mjs`
2. `main` 푸시: 검사를 통과하면 `index.html`, `css`, `js`만 모아 GitHub Pages에 배포

저장소 **Settings → Pages → Build and deployment → Source**를 **GitHub Actions**로 설정해야 합니다.

## 브랜치 규칙

`main`에는 직접 커밋하지 않고 기능 브랜치에서 작업한 뒤 PR로 병합합니다.
