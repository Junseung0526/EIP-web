# 정처기 중간고사 마스터

정보처리기사 1·2과목 중간고사 대비 학습 사이트. 교수님이 지정한 범위(64개 항목)를 **SVG 도해 + 인터랙티브 시뮬레이터 + 예상문제 + 암기카드**로 정리했습니다.

- 빌드 도구 없는 순수 HTML/CSS/JS (정적 사이트)
- 모든 도해는 JS로 생성하는 인라인 SVG (다크 모드 대응)
- 진도·오답 노트·카드 암기 상태는 브라우저 `localStorage`에 저장

## 구성

| 구분 | 내용 |
|---|---|
| 학습 페이지 68개 | 1과목(개발 모형·요구사항·UML·UI·아키텍처·객체지향·GoF 23패턴) / 2과목(자료구조·정렬·해싱·패키징·DRM·형상관리·테스트·EAI·JSON·IPSec) |
| 시뮬레이터 | 트리 순회(전/중/후위 경로 애니메이션), 중위→후위 변환기(스택 표·수식 트리), 스택, 정렬 4종 단계 재생, 해시 테이블(충돌 해결), 그래프 최대 간선 수, 트리 차수, JSON 분석 |
| 문제풀이 | 157문항, 주제/과목/오답 노트/모의고사(20문항) |
| 암기카드 | 주제별 카드 + GoF 패턴 카드 자동 생성 |

> 문제 은행은 기출 **유형**을 바탕으로 만든 예상문제입니다. 교수님이 직접 언급한 2문항(영어 문제, 정렬 복잡도)만 실제 출제 문항이며 `src: 'prof'`로 표시했습니다. 용어는 수업 자료와 대조해 확인하세요.

## 로컬 실행

```bash
python3 -m http.server 8000   # 후 http://localhost:8000
# file:// 로 index.html 을 직접 열어도 동작합니다.
node scripts/check.mjs        # 데이터 무결성 검사 (토픽·범위·퀴즈 참조/정답 인덱스)
```

## 배포 (GitHub Pages)

`.github/workflows/deploy.yml` 이 `main` 푸시 시 검사 → 배포를 수행합니다. PR에서는 검사만 실행됩니다.

1. 저장소 **Settings → Pages → Build and deployment → Source** 를 **GitHub Actions** 로 설정
2. `main` 에 병합하면 자동 배포
